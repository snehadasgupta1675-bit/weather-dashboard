# 🌤️ Weather Dashboard

A real-time weather dashboard built using HTML, CSS, and JavaScript. It fetches live weather data from a public REST API and displays weather information based on the city entered by the user.

## 🚀 Features

- Search weather by city name
- Live temperature
- Humidity
- Wind speed
- Weather description and icon
- Loading message
- Error handling
- Current date and time
- Search using Enter key
- Responsive design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Fetch API
- REST API
- Async/Await
- JSON

## 🎯 Objective

To understand asynchronous JavaScript, RESTful APIs, Fetch API, JSON data processing, error handling, and dynamic DOM manipulation.
